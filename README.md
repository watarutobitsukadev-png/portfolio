# 飛塚渉 ポートフォリオサイト

Web制作の就職活動用に作成した、個人のポートフォリオサイトです。

## サイト構成

- トップページ(index.html)に自己紹介・スキル・制作実績・お問い合わせをまとめた1ページ構成
- 各作品の詳細ページはworksフォルダ内に個別に用意

## 掲載している制作実績

1. **架空キャンプ場「SoraCamp」公式サイト** — 静的サイト(HTML/CSS/JavaScript、Illustratorで場内マップを作成)
2. **手ぶらグランピング新プランLP** — ランディングページ(構成・文言は自作、コーディングはAIツールの支援を受けて実装)
